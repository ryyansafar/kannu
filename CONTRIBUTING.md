# Contributing

1. Write a failing test first, then the fix.
2. Run `python -m pytest -q`; keep coverage at or above 80%.
3. Never drive a Pi pin the code was not told about; flag any 5 V signal.
4. Plain code decides; the agents' work is judged by tests they did not write.
